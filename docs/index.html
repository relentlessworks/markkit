markkit

Agentic-First Markdown Processing Service

Go CGO_ENABLED=0 Single Binary MCP MIT
View on GitHub Download

Quick Start

# Build
make build

# Run
./markkit

# Convert Markdown to HTML
curl -X POST localhost:8470/render -d '# Hello World'

# Extract plain text
curl -X POST localhost:8470/extract -d '**bold** and `code`'

# Generate table of contents
curl -X POST localhost:8470/toc -d '# Title
## Section'

# Get document statistics
curl -X POST localhost:8470/stats -d '# Hello

Some text here.'

# Convert HTML to Markdown
curl -X POST localhost:8470/html2md -d '<h1>Title</h1><p>Text</p>'

Principles

Agent IS the Interface

No UI, no SDK. The API is the product.

Plain Text by Default

Token-cheap, grepable, survives context truncation.

Instructive Errors

Every 4xx includes a hint for self-correction.

Self-Documenting

GET /help returns the operating manual.

Single Static Binary

Go, CGO_ENABLED=0, zero external dependencies.

Zero Config

Runs out of the box with sensible defaults.

MCP Connector

Speaks Model Context Protocol at /mcp.

Stateless

Pure computation, no database needed.
